# Data-driven ABCD

This repository provides implementations of a **data-driven scheme** for computing abstractions of dynamics in continuous cyber-physical systems. The abstractions are **provably valid up to a high confidence bound** and can be used to synthesize abstraction-based controllers for diverse classes of dynamical systems, with applications in **robotics, transportation, and energy systems**.

📄 For further details, see our paper: [link](https://www.sciencedirect.com/science/article/pii/S1751570X24000049).
